# STM32 UART Command Shell

A small command shell for the NUCLEO-C031C6 board. The board talks to a serial terminal on a PC over UART and controls the on-board LED based on what the user types.

## Hardware

- Board: NUCLEO-C031C6 (STM32C031C6, Arm Cortex-M0+)
- Connection: USB to the on-board ST-LINK, which also provides the virtual COM port

| Function       | Pin  | Notes                         |
|----------------|------|-------------------------------|
| User LED (LD4) | PA5  | Output                        |
| User button    | PC13 | Input (not used yet)          |
| USART2 TX      | PA2  | Connected to ST-LINK VCP      |
| USART2 RX      | PA3  | Connected to ST-LINK VCP      |

## Current features

- Line-based input: characters are collected until Enter is pressed
- Typed characters are echoed back to the terminal
- Backspace removes the last character, both from the buffer and on screen
- Input is limited to the buffer size; extra characters are ignored
- Commands:
  - `led on` turns the LED on
  - `led off` turns the LED off
  - `blink led` blinks the LED four times
- Unknown commands are reported

## Implementation notes

- UART communication uses the STM32 HAL in polling mode.
- The LED driver (`led.c`) writes the GPIO output register directly instead of using HAL calls.
- Peripheral initialisation (clocks, GPIO, USART2) is generated by STM32CubeMX from `command_shell.ioc`.

## Project structure

```
Core/
  Inc/        Header files (led.h, main.h, ...)
  Src/        Application code (main.c, led.c) and generated sources
  Startup/    Startup code and vector table
Drivers/      STM32C0 HAL and CMSIS
command_shell.ioc        STM32CubeMX configuration
STM32C031C6TX_FLASH.ld   Linker script
```

## Building and running

1. Open the project in STM32CubeIDE (File > Open Projects from File System).
2. Build the project and flash it to the board.
3. Open a serial terminal on the board's virtual COM port with these settings: 115200 baud, 8 data bits, no parity, 1 stop bit.

   On macOS, for example:

   ```
   screen /dev/tty.usbmodemXXXX 115200
   ```

4. Type a command and press Enter.
